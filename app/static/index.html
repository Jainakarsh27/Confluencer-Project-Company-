ARCHITECTURAL SOUNDNESS

Engineered For Financial Invariance

Every transaction adheres to non-negotiable double-entry accounting rules with database-level constraints.

Pessimistic Row-Locking Concurrency Control

During financial disbursements, LedgerFlow acquires an exclusive row lock (SELECT ... FOR UPDATE) on the account balance. Simultaneous debit operations across multiple threads or background processes are strictly serialized, mathematically guaranteeing an account balance can never drop below zero.

SQLAlchemy 2.0 with_for_update() Check Constraint balance ≥ 0 Passes 5x Race Test

Idempotency Replay Defense

Composite unique constraint on (account_id, reference_id) ensures network retries or malicious duplicate postings are rejected with HTTP 409 Conflict, without corrupting state.

Zero Floating-Point Precision

Strict use of Python Decimal and SQL NUMERIC(18, 2) prevents binary floating-point drift (e.g. 0.1 + 0.2 != 0.3). Fractional cents and non-positive amounts are rejected.

Diagnostic Balance Reconciliation Service

A dedicated read-only diagnostic service recalculates the total sum of all immutable credit and debit entries ($\sum \text{Credits} - \sum \text{Debits}$) and compares it against the stored materialized balance. Discrepancy tolerance is zero.
